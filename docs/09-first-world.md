# Первый мир

> Документ-спецификация первого мира: онбординг, загрузка, графика, экономика.
> Все цифры — **оценки** (калибровать на своих тестерах).

---

## 1. Что такое «первый мир»

**[оценка]** Первый мир — это **не** демо-уровень и **не** полигон для графики. Это
**экономический и социальный прототип**: минимальный мир, в котором уже работают
передача ценности, торговля и онбординг, но который ещё можно переделать за неделю.

**Границы первого мира:**

| Есть | Нет |
|---|---|
| 1 мир, 3–4 зоны (хаб + 3 зоны) | Процедурная генерация бесконечных планет |
| Своя валюта + ledger + торговля | Несколько валют, вывод в фиат |
| Чат, торговля, размещение объектов, заказы | Полноценный PvP, рейды, гильдии |
| Адаптивная графика (3 уровня) | «Красивый» мир целиком — только одна демо-зона |
| 20–50 постоянных игроков | Тысячи онлайнов (но шардинг должен выдержать) |
| Модерация ручная | Автомодерация ИИ |

**Критерий успеха первого мира:** новый человек, зашедший по ссылке, **за 10 минут
понимает, что здесь можно делать**, и **за 30 минут зарабатывает первые деньги
и тратит их**. Не «нашёл квест», а «включился в жизнь мира».

## 2. Онбординг: первые 10 минут

**[оценка] Принцип: учим социальные глаголы, а не гриндим.**

Каждое задание первых 10 минут должно: (а) быть возможно только с другими игроками
или в их присутствии, (б) учить один глагол, (в) давать ощутимый, но небольшой заработок.

| Время | Событие | Учим | Награда |
|---|---|---|---|
| 0:00 | Вход по ссылке → выбор аватара с живым 3D-превью | — | — |
| 0:30 | Спавн в **Хабе**: видно других игроков, доска заказов, киоск валюты, 3 телепорта | «здесь есть люди» | — |
| 1:00 | **Задание 1:** поздороваться / помахать 3 игрокам | жест, чат | 5 ¤ |
| 2:30 | **Задание 2:** взять заказ с доски (принести 3 дерева) | заказ, предметы | 10 ¤ + доступ в зону |
| 5:00 | **Задание 3:** передать/продать предмет другому игроку | торговля | 15 ¤ |
| 7:30 | **Задание 4:** поставить или изменить объект в мире | UGC | 20 ¤ |
| 10:00 | Свободный режим: зоны, торговля, аренда места, общение | — | — |

**[статус 27.10]** Это спека, а не текущий клиент. В `main` есть: анонимный
вход по ссылке (сервер выдаёт ник `guest-XXXX`), экран «как играть»,
процедурное тело (F1-4, но не выбор аватара), видимость других игроков,
чат, телепорты и genesis-грант (100 ¤, а аккаунту моложе суток — 20 %, то
есть 20 ¤). Нет: выбора аватара с
превью, доски заказов, четырёх заданий с наградами, киоска валюты и аренды.
Возвращаемся к этому в фазе 3 вместе с экономикой (см. `11-work-plan.md`, §4.3).

**[оценка] Почему не «вручную бить слизней»:**
- Гринд — это **налог на новичка**: время, которое можно было потратить на знакомство
  с людьми, тратится на обучение, которое обслуживает только его.
- Для социальной платформы это худший дизайн: мы отнимаем у новичка ровно то время,
  за которое он мог бы понять, зачем ему этот мир.
- Слизи — это **контент**, а не онбординг. В Roblox в хабе тоже есть мини-игры, но они
  добровольные.
- Компромисс: слизи/NPC-заказы остаются, но как **точка входа в рынок** — NPC-бюрократ
  выдаёт заказ, а не «враг для наказания».

## 3. Загрузка: декомпозиция проблемы

**[оценка]** «Будет грузиться полчаса» — это правда **только при наивной реализации**.
Разложим «загрузку» на части, каждая из которых управляема:

| Этап | Что именно | Типичная доля | Как чиним |
|---|---|---|---|
| 1. Bootstrap | JS-бандл клиента | 10–20% | gzip/brotli, code-splitting, lazy-load модулей |
| 2. Init GPU | device, pipeline, **компиляция шейдеров** | 20–40% | `createRenderPipelineAsync`, `KHR_parallel_shader_compile`, warm-up сцена в фоне |
| 3. Ассеты | текстуры, меши, звук | 30–60% | streaming по зонам, LOD, GPU-компрессия, CDN |
| 4. Данные мира | world.json, снапшот сектора | 5–15% | клиент рисует **до** снапшота, не блокируя |
| 5. Первый кадр | рендер | — | — |

### 3.1 Бюджет «красивой» зоны (оценка)

| Компонент | Размер (сжатый) | Примечание |
|---|---|---|
| Текстуры (KTX2 / BC7 / ASTC) | 3–8 МБ | GPU-native, без декодирования на CPU |
| Меши (meshopt) | 0.5–2 МБ | meshopt декодируется быстрее Draco |
| Звук (Opus/AAC) | 1–3 МБ | стримим по мере надобности |
| Код зоны (логика, триггеры) | 50–300 КБ | часть world.json |
| **Итого зона** | **6–15 МБ** | база мира — процедурная, стоит 0 байт |

**Целевые тайминги:**

| Метрика | Цель |
|---|---|
| Time to first frame (хаб) | ≤ 5 с на 20 Мбит/с |
| Time to interactive | ≤ 8 с |
| Переход между зонами (с prefetch) | ≤ 3 с |
| Повторный вход (PWA-кэш) | < 1 с |

**[оценка] Главное правило: загрузка — это зоны, а не мир.** Мир грузится никогда целиком.

### 3.2 Приёмы, которые реально работают

1. **Зона = единица загрузки.** Хаб — одна зона, каждая зона — отдельный набор ассетов.
   Префетч следующей зоны при приближении телепорта.
2. **Никогда не блокировать первый кадр на сервере.** Клиент рисует сразу
   (client-side prediction + оптимистичный спавн), мир «проявляется» вокруг.
3. **GPU-native сжатие текстур.** KTX2 + Basis Universal: экономит 4× против PNG
   и снимает декодирование на CPU (в WebGL2 без расширений — заметно).
4. **Meshopt** вместо Draco (скорость декодирования) + инстансинг + атлас текстур.
5. **Запечённое освещение** (lightmaps) вместо realtime-теней: одна текстура на зону
   вместо каскада shadow maps. Тени — только на T1/T2 и только для динамики рядом.
6. **Параллельная компиляция шейдеров** в фоне, пока игрок читает текст на экране.
7. **PWA + Cache Storage**: второй заход — почти мгновенно (ассеты иммутабельны,
   URL с хэшем → cache-friendly).
8. **Параллельные потоки**: сеть и рендер не блокируют друг друга (NetworkWorker,
   AssetWorker).
9. **Никакого мусора в клиенте:** нет рекламных SDK, аналитики, голосового чата в v1.
   Это реально ускоряет бутстрап и уменьшает бандл.

### 3.3 Адаптивная графика: три уровня

**[оценка]** Реальность нашей воронки: ссылка в Telegram → случайные устройства.
Значит, ориентируемся на **медианное** устройство, а не на лучшее.

| Параметр | T0 (низкий) | T1 (средний) | T2 (высокий) |
|---|---|---|---|
| Устройство | телефон, встройка, старый ПК | средний ноутбук | современный десктоп |
| renderScale | 0.6–0.75 | 1.0 | 1.0–1.5 |
| Тени | выкл | 1 карта 1024 | каскад 2048 |
| Post-FX | выкл | bloom | bloom + SSAO + TAA |
| Дальность прорисовки | 60 м | 120 м | 250 м |
| Draw calls | < 300 | < 800 | < 2000 |
| Треугольников в кадре | < 80k | < 250k | < 600k |
| VRAM текстур | < 128 МБ | < 384 МБ | < 1 ГБ |
| Уровень текстур | mip 2–3 | mip 1 | mip 0 |

- Определение tier: `navigator.gpu.requestAdapter().info` + `WEBGL_debug_renderer_info`
  (в части браузеров поля адаптера редактируются для анти-фингерпринтинга —
  нужен fallback по бенчмарку).
- **Тот же URL ассета отдаёт разное качество** через mip-уровни в KTX2-контейнере.
- Игрок может **сам** переключить уровень в настройках.

### 3.4 Про «яркую рекламу» и «5 минут загрузки» в Roblox

**[оценка]** Разбор:
- Roblox выглядит «лоу-поли» не из лени, а потому что его **целевая платформа** —
  телефоны и очень старые ПК, а аудитория огромна и разношёрстна. Там серьёзная
  оптимизация: инстансинг, агрессивный LOD, атласы, кастомные шейдеры.
- «5 минут загрузки игроков, функций и всплывашек» — это **бутстрап клиента**,
  загрузка фич-модулей и рекламных SDK, а не мир. У нас этого мусора нет by design.
- Реклама — следствие модели «деньги с неплатящих». У нас модель другая
  (см. D-006) → рекламу не тащим.

**[оценка] Стратегия «красивой графики»:**
> **Не делать весь мир красивым. Сделать одну зону красивой, а базу — лёгкой.**

Красота концентрируется в: (а) хабе — это витрина, первые 30 секунд впечатления;
(б) одной «художественной» зоне, куда можно телепортироваться;
(в) **пользовательском контенте** — то, что создают игроки, может быть красивее
нашего базового набора, и это ещё и вовлечение.

## 4. Экономика: как запускается мир

### 4.1 Разделим два вопроса

| Вопрос | Ответ |
|---|---|
| Когда «стартует» сервер? | **Не должен перезапускать экономику.** Рестарт процесса ≠ новый мир. Сегодня ledger по умолчанию в памяти (`STORAGE=memory` — рестарт обнуляет балансы), а `PostgresLedger` уже написан и включается `STORAGE=postgres` + `DATABASE_URL`; снапшоты секторов восстанавливаются из мира |
| Когда «стартует» мир? | Один раз, при создании. Реальная команда сегодня: `npm run generate:world -w @oasis/server` — seed лежит в `content/default/world.json`, CI сверяет файл с выводом генератора. `world create --seed ... --genesis ...` так пока не написано. Всё дальнейшее — настройки, а не пересоздание |

**[оценка] Правило: деньги не минтятся при рестарте сервера.** Если бы минтились —
каждый деплой разбавлял бы экономику, а игроки об этом узнали бы мгновенно.

### 4.2 Genesis: как задаётся размер денежной массы

**[оценка]** Не «банк», а **скорость эмиссии**. Ключевой параметр — не сумма, а поток:

```
faucet_rate_per_day = min(cap_per_account, f(active_players))
genesis_grant       = одноразовый, ≈ стоимость 2–3 действий новичка
genesis_reserve     = эмиссионный резерв мира, выдаётся по мере активности
```

**[оценка] Почему не раздать всем при старте:**
100 аккаунтов × 100 кредитов = 10 000 кредитов, которые **нечем тратить** →
все копятся → Gini ≈ 1.0, ликвидности ноль, экономика мертва при живых игроках.
Правильно: **эмиссия скоростная и привязана к активности**, а не разовая.

### 4.3 Стартовый баланс: одноразовый грант + дневной кран

| Механизм | Что | Защита от мультиаккаунтов |
|---|---|---|
| **Genesis grant** | Одноразово при первом входе в мир, размер ≈ на 2–3 первых действия | Один раз на аккаунт; **полный размер — только для аккаунтов с возрастом > N дней или прошедших human-check**; свежий аккаунт получает 10–20% |
| **Faucet** | 3–5 заданий в сутки, суточный кап по аккаунту | Кап считается на аккаунт; ценность копилки обесценивается временем |
| **Сток** | Аренда места, комиссия торговли, ремонт, телепорт | — |

**[оценка] Ключевой приём против сибил-ферма:** грант привязан к **возрасту аккаунта**,
а не к факту регистрации. Миллион свежих аккаунтов даёт 10–20% гранта, а не 100%.
Это стоит одну строчку в ledger и закрывает самый дешёвый способ надуть экономику.

### 4.4 Кто даёт работу

**[оценка]** В первом мире — **NPC-бюрократы** (точка входа в рынок), а не NPC-агенты:

- NPC выдаёт заказ: «принеси 3 дерева → 10 ¤»;
- NPC принимает товар и платит;
- NPC **не торгует** предметами, не покупает у игроков, не конкурирует за заказы.

**[канон]** Это и есть «телепресенс» из романа: в каноне Уэйд живёт на заработке
внутри мира. Наш аналог — игрок, который делает для других то, что они не хотят/не умеют.

### 4.5 Стартовые метрики первого мира

| Метрика | Цель |
|---|---|
| Доля новых игроков, завершивших онбординг (10 мин) | > 60% |
| Доля игроков, торговавших в первые 30 мин | > 30% |
| Медианный баланс после 24 ч | > 0 |
| Gini по балансам на 7-й день | < 0.6 |
| Оборот валюты (velocity) | > 0.5 |
| Доля аккаунтов, получивших полный genesis grant | < 30% (значит, грант не раздаётся направо) |

## 5. Правила первого мира

| Правило | Значение | Почему |
|---|---|---|
| PvP | **выкл** во всех зонах первого мира | Первый мир — про знакомство, а не про драки |
| Магия/техника | только базовые флаги (1 зона с «магией» как демо флагов) | Проверяем механику флагов из канона |
| Телепорт | 3 точки: хаб ↔ зона 1 ↔ зона 2 | Учим перемещение, но не делаем «спидран» |
| Коммуникация | чат + жесты + «чат доска заказов» | Минимальный набор для социализации |
| Владение | 1 арендуемый участок в хабе | Учим владению без риска «инвестиции» |
| Экономика | closed loop, без вывода в фиат | См. D-005 |

## 6. Чек-лист готовности первого мира

**Мир**
- [ ] 3–4 зоны, world.json + seed, версионирование
- [ ] Хаб со 100+ объектами и NPC-киоском
- [ ] Телепорты между зонами, prefetch следующей зоны

**Онбординг**
- [ ] Выбор аватара с живым превью
- [ ] 4 задания, каждое учит один глагол
- [ ] Подсказки в контексте, а не туториал-стена
- [ ] Замер: 80% новичков понимают, что делать, за 2 минуты без нас

**Загрузка**
- [ ] Time to first frame ≤ 5 с на 20 Мбит/с
- [ ] Переход между зонами ≤ 3 с
- [ ] Адаптивный tier (T0/T1/T2) + переключатель в настройках
- [ ] PWA-кэш: повторный вход < 1 с

**Экономика**
- [ ] Genesis grant с привязкой к возрасту аккаунта
- [ ] Faucet с суточным капом, начисление в append-only ledger
- [ ] Торговля: игрок ↔ игрок (escrow на сервере)
- [ ] Аренда участка + комиссия (стоки)
- [ ] Дашборд: эмиссия/стоки/velocity/Gini

**Проверки**
- [ ] Ни один реальный день не проходит без ручного входа в мир (иначе вы не заметите проблем)
- [ ] 20 человек из Telegram-чата зашли по ссылке и остались дольше 20 минут
- [ ] Замеры загрузки на 3 реальных устройствах, а не на своём ноутбуке
