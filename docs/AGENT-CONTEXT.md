# OASIS — краткий контекст для агента

**Читай этот файл первым.** Он короче плана и нужен, чтобы после сброса
контекста не начинать заново «не с того места».

## Суть проекта

«Оазис» — протокол и ядро безграничного виртуального мира по мотивам
«Первому игроку приготовиться». Фокус не на квестах, а на **открытом
протоколе**: федерация миров, переносимость личности и имущества.
Отличие от Roblox — открытость, а не замкнутая экосистема.

Команда: 2 человека part-time (~15–20 ч/нед каждый), бюджет 100–300 тыс. ₽,
юрисдикция РФ. Клиент — веб (Three.js: WebGPU + WebGL2 фоллбэк).

## Стек

- Монорепо npm workspaces: `packages/protocol`, `packages/server`, `packages/client`
- Node 26 + TypeScript 5.9 + tsx, zod 4, express 5, Vite 8
- Colyseus 0.18 (сервер-авторитет, фиксированный тик 20 Гц)
- Three.js 0.186, предсказание + сверка на клиенте
- Хранилище: память по умолчанию, Postgres/Redis — опционально

## Известные особенности, чтобы не искать заново

- **Потолок кадра на клиенте — 400 мс** (`packages/client/src/net/frameDelta.ts`).
  При 100 мс предсказание на 3–15 fps шло медленнее реального времени,
  сервер уходил вперёд, сверка тянула игрока за ним. Зонд видел
  «14 м за 1.5 с» при скорости 5 м/с. Это ловится тестом и мутацией 400→100.
- Зонды меряют **тики**, а не миллисекунды: в headless-CI 3–15 fps.
- Через `http://<IP>` нет `crypto.randomUUID()` — используется фоллбэк на
  `crypto.getRandomValues`.
- Cookie-авторизация требует `credentials: 'include'` и CORS `credentials: true`.
- Имена уникальны внутри сектора (суффикс ` (2)`). В фазе 2+ планируется
  разделить `handle` (логин, уникальный) и `displayName` (неуникальный).
- `npm run test:browser` требует свободные порты 2567 и 5173. Убивать
  процессы только через `lsof -ti:2567,5173`, не через `pkill -f "vite"`:
  такой pkill убивает и собственную команду агента.

## Правила работы

- Не пушить напрямую в `main` — branch protection (PR + 1 апрув + чеки,
  админы тоже не обходят)
- Любое изменение протокола — ревью второго + bump `PROTOCOL_VERSION`
- Тест обязан ловить свой баг: новая защита = новая мутация в
  `scripts/mutation-check.mjs`
- Зонды не должны зависеть от fps
- Общаться по-русски
