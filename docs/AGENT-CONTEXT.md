# OASIS — краткий контекст

## Суть проекта
«Оазис» — протокол и ядро безграничного виртуального мира по мотивам «Первому игроку приготовиться».
Фокус не квест/игра, а **протокол-first** платформа с открытым протоколом, федерацией, переносимостью личности/имущества.
Отличие от Roblox — открытость, а не замкнутая экосистема.

## Стек
- Монорепо (npm workspaces): `packages/protocol`, `packages/server`, `packages/client`
- Node 26 + TypeScript 5.9, tsx
- Colyseus 0.18, Three.js 0.186 (WebGPU + WebGL2 фоллбэк)
- zod 4, express 5, Vite 8
- Postgres/Redis в конфиге (сейчас dev в памяти)
- Сервер-авторитет, фиксированный тик 20Гц, предсказание + реконсиляция

## Что сделано
- Вертикальный срез рабочий
- Протокол v0.3.0, бинарный канал + JSON
- Движение, зоны, порталы, чат, переименование ников
- F0-8: реконнект/возврат на место при обрыве/F5 (токен в sessionStorage, захват места по токену/аккаунту)
- CI: `typecheck+tests`, `browser`, `mutation` — все зелёные

## Правила
- Работать в ветке, не пушить напрямую в `main`
- Любое изменение протокола — ревью второго + bump версии
- Тест должен ловить свой баг (проверка мутациями)
- Зонды не завязаны на fps
- Общаться на русском
