## 5. Наши оценки (не факты!)

| Оценка | Значение | Как получено |
|---|---|---|
| Стоимость игро-часа | $0.01–0.02 | Средний VPS + трафик + CDN + storage, амортизировано на 100+ DAU |
| 10k concurrent | $4–12 тыс./мес | ~0.5–1.0 $/час concurrent-игрока при ~100% утилизации |
| 100k DAU | $5–15 тыс./мес | ~1.5 ч/день на игрока |
| Стоимость старта (3 мес.) | 10–25 тыс. ₽ | 2 VPS + домен + S3/CDN + мониторинг |
| Сроки фаз 0–5 | 9–12 мес. part-time | ~30 ч/нед на двоих, спринты по 2 недели |
| Latency p95 (edge) | 60–120 мс | Edge в РФ/ЦВ, WebSocket, снапшоты 10–20 Гц |
| Время до первого кадра | < 8 с | CDN + прогрессивная загрузка секторов |
